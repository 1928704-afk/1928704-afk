### 💡 About Me

- ⚙️ **견고한 백엔드 아키텍처:** Java와 Spring Boot 기반으로 유지보수성과 확장성을 고려한 RESTful API를 설계합니다.
- 🗄️ **데이터 중심의 고민:** MySQL을 활용하여 효율적인 데이터 모델링과 쿼리 최적화에 관심이 많습니다.
- ☁️ **인프라 & 배포:** AWS 클라우드 환경을 이용해 안정적인 서비스 배포 및 운영 환경을 구축합니다.
- 🔄 **원활한 풀스택 협업:** React 개발 경험을 바탕으로 프론트엔드의 동작 흐름을 이해하고 클라이언트 친화적인 API를 제공합니다.
